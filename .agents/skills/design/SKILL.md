# Design Skill

Core principles, craft floors, typography systems, geometric rules, and aesthetic refinement techniques for technical presentations and documents.

## Core Design Philosophy

- Intentionality over Decoration: Every visual element (container, border, color tint, shadow) must earn its place by communicating hierarchy, state, or mathematical/logical meaning.
- Editorial Voice: Authoritative, decisive, and expert. Speak with confident taste; eliminate hedging language (such as "might consider" or "perhaps") and commitment avoidance.
- Anti-Slop Discipline: Refuse generic automated defaults including nested cards, gratuitous numbering (01/02/03), gradient text, eyebrow kickers, and emoji bullets.
- Ruthless Distillation: Deliver high information density with minimal visual clutter. Limit prose to ~40 words per slide and let clear diagrams and typography carry the argument.
- The Squint Test: A blurred view of any slide must still reveal clear visual hierarchy, primary focus, and reading path.
- The Skeleton Test: Stripping all copy out of a layout must leave a clear structural hierarchy that communicates without words.
- Greenfield Design Sequence: Define the visual thesis, build the structural skeleton, place the primary exhibit, establish supporting hierarchy, and verify against the craft floor.

## Design Craft Rules

- Spacing and Grouping: Group related elements by proximity before adding container boxes or borders.
- Typographic Scale: Use a strict, proportional font scale (22-26pt slide headings, 16-20pt body text, >= 14pt captions/annotations) with >= 1.25x ratio between steps.
- Color Restraint: Use at most 3 semantic hues (dominant brand/accent, secondary comparison, optional alert) on top of neutral grounds.
- Contrast Standards: Maintain >= 4.5:1 contrast ratio for body text and >= 3.0:1 for large display titles.
- Action Titles: State the takeaway as a complete sentence for every slide title.
- Geometric Concentricity: When nesting rounded containers, calculate inner radius as outer radius minus container padding.
- Data and Chart Clarity: Label chart series directly instead of relying on detached legends. Use tabular figures for aligned numbers.
- Intensity Modulation: Make bolder passes by amplifying existing elements with one decisive move; make quieter passes by lowering saturation and expanding whitespace.
- Cognitive Motion: Use animations and progressive reveals only to explain state transitions, sequence logic, and mathematical derivations.
- Hardening and Edge Cases: Enforce zero text overflow, align multi-line equations, and ensure consistent variable notation across text and diagrams.
- Earned Visual Moments: Elevate key takeaways and neural architectures through precise vector craft and cohesive palette harmony.
