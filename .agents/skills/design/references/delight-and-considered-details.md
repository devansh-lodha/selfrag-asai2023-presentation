# Considered Details and Earned Visual Moments

Guidelines for introducing memorable craft and visual polish without generic whimsy.

## 1. The Earned Delight Principle

Delight in academic and technical presentations comes from precision, analytical clarity, and elegant visual explanations:
- Never add generic whimsy, celebratory illustrations, or decorative animations.
- Delight is earned when a complex mathematical intuition or architecture becomes immediately obvious through a well-crafted diagram.

## 2. Opportunities for Visual Craft

- The Architecture Hero: A beautifully laid out Fletcher neural network diagram with crisp nodes, aligned arrows, and subtle layer color coding.
- The Key Result Peak: An uncluttered comparison chart or table highlighting the primary empirical breakthrough with a distinct accent fill.
- The Intuition Bridge: A side-by-side comparison illustrating why reversing the source sequence reduces minimal time lag in LSTM memory cells.
- The Seamless Transition: Using progressive reveals (`uncover`) where mathematical state equations highlight in tandem with data flowing through network nodes.

## 3. High-Craft Micro-Details

- Optical Alignment: Aligning arrow start and end anchors precisely to node boundaries rather than approximate coordinates.
- Proportional Stroke Weights: Matching border stroke weights on callout cards (1pt) with edge stroke weights in diagrams (1pt).
- Palette Harmony: Using the exact same primary accent hex code across slide headings, callout left borders, and active network layers.
- Concentric Corner Geometry: Nested containers maintain matching curvature by reducing inner radius by the padding width.
